\chapter{Supplementary Results}
\label{app:tables}

This appendix collects secondary results referenced from the main text. Complete
per-benchmark, per-configuration tables (including all baselines: BM25, dense
RAG, attention memory, and the per-document-tuned \Vt{}) are provided in the
accompanying code repository, alongside the per-benchmark
\texttt{*\_corpus\_summary.json} aggregates.

\section{Neural memory controller (exploratory)}
A neural variant replaced the ten scalar parameters with a small MLP
($50\rightarrow32\rightarrow10$, $\sim$1{,}962 parameters) tuned by the same
CMA-ES budget. On MultiHopKeyDoor it reaches a best fitness of $0.233$ and a
held-out reward of $\sim$0.19 --- matching or slightly exceeding the scalar
\Vfour{} --- but with far more parameters and no clear robustness advantage, and
it fails zero-shot on the larger out-of-distribution task just as the scalar
version does. The conclusion is that the extra expressivity of a neural
controller is not needed at this scale; the ten-scalar parameterization is a
strong, cheap baseline. Full details are in the accompanying code repository.

\section{Verbal self-reflection (negative result)}
A Reflexion-style \citep{shinn2023reflexion} augmentation, in which the agent
writes verbal self-feedback into memory between attempts, did not improve
end-task performance in our setting: the learned-memory parameters already
capture the useful signal, and free-text reflections added noise rather than
durable structure. We report this negative result for completeness; full details
are in the accompanying code repository.

\section{Stage-2 detail}
The full twelve-system rankings per environment, the per-component ablation
table, the cross-environment transfer matrix, and the 2-D sensitivity grid are
reproduced from the committed results by
\texttt{python generate\_thesis\_figures.py}. All figures and tables in this
thesis use the MiniLM sentence-embedding backend (\texttt{all-MiniLM-L6-v2}),
\emph{except} the Stage-2 grid benchmark figure (Figure~\ref{fig:stage2bench}),
whose $0.178$ top-cluster tie is from the earlier TF-IDF backend. This ranking is
backend-sensitive: under MiniLM the absolute rewards shift and \Vfour{} is
competitive with, but does not lead, the strongest baselines --- the honest
reading recorded in the Stage-2 self-audit (Appendix~\ref{app:honesty}). All
Stage-3 (real-LLM) results use MiniLM throughout.
